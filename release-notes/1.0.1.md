A reliability update: downloads that no longer drop in the middle, and a window that keeps answering on ad-heavy pages.

### Downloads that finish

- A big download no longer stops with "The operation was canceled." when one connection times out. Before, one connection
  that timed out stopped all of them; now only that connection is opened again, from where it stopped.
- A connection that goes silent (the server leaves it open but sends nothing) is cut after 30 seconds and opened again,
  instead of waiting for ever.
- A connection that keeps failing hands its part of the file to the others, so one bad connection never ends the download.
- Retries are patient: any try that brings new bytes resets the count, waits between tries grow up to a minute, and while
  the computer is offline Vireo waits for the internet to come back instead of giving up.
- A file host that answers "too many requests" gets fewer connections, so the download carries on instead of being refused.
- When a download does fail, the reason is written in plain words.

### Keep downloading after closing the browser

- Closing Vireo while downloads run now asks whether to keep downloading in the background. If you do, the browser and its
  page engine close completely, and only the downloader stays, with an icon in the notification area by the clock: about
  40 MB of memory instead of several hundred. Hovering shows the progress; clicking opens a small window with every download,
  pause, resume and cancel, and "Open Vireo" to bring the browser back without interrupting them. When they are all done,
  Vireo says so and exits. "Don't ask again" (or Settings, Downloads) makes the choice for every time.

### Smoother and steadier

- The side panel and the side tab list slide instead of resizing the page on every frame, moving cards are drawn once rather
  on every frame, the window's background is drawn once, and only figures use the extra text feature that keeps digits
  steady, so animations stutter less, most on slower laptops.
- The ⋯ menu opens quicker: measuring memory no longer scans every process on the computer.
- The menu, notices, address suggestions, the find bar and extension pop-ups never show over other programs.
- Settings: long choices such as "DuckDuckGo" are no longer cut off, and the Updates row fits a narrow panel.

### No more freezes on ad-heavy pages

- Some news sites' ad code asks for the same blocked address again the moment it is refused, hundreds of times a second.
  That load could make the window stop answering for several seconds. Vireo now refuses such a loop more and more slowly
  (the ad still never loads), which cut the requests on one news site from about 72,000 to about 600 in four minutes.
- The shield's number no longer shakes or jumps to "999+": it counts each blocked address once, keeps a steady width, and
  updates at most four times a second.
